# 1 화학결합 {#bond}

원본 1쪽 「共有結合 · イオン結合 · 金属結合」을 한국어로 풀었습니다. 시험에서는 **어떤 원자끼리 붙었는지를 보고 결합의 종류를 고르는 문제**가 가장 자주 나옵니다.

## 용어 정리

| 일본어 | 한국어 | 뜻 |
|---|---|---|
| 共有結合 | 공유결합 | 두 원자가 홀전자(不対電子)를 하나씩 내놓아 전자쌍을 만들고, 그 전자쌍을 함께 가지는 결합입니다. |
| 共有電子対 | 공유전자쌍 | 공유결합에서 두 원자가 함께 가진 전자쌍입니다. |
| 配位結合 | 배위결합 | 한쪽 원자만 비공유전자쌍(非共有電子対)을 내놓고, 그것을 다른 원자와 함께 가져서 생기는 결합입니다. |
| 電気陰性度 | 전기음성도 | 공유전자쌍을 자기 쪽으로 끌어당기는 힘을 수치로 나타낸 값입니다. |
| イオン結合 | 이온결합 | 양이온과 음이온 사이의 정전기적 인력(쿨롱힘)으로 이온끼리 붙는 결합입니다. |
| 金属結合 | 금속결합 | 금속원자의 원자가전자(価電子)가 자유전자(自由電子)가 되어 여러 금속이온 사이를 돌아다니며 만드는 결합입니다. |
| 分子 | 분자 | 몇 개의 원자가 공유결합으로 이어진 입자입니다. |

## 꼭 외울 것

- **전기음성도**는 비활성기체(貴ガス)를 빼고 주기율표의 **오른쪽 위로 갈수록 큽니다**. 가장 큰 원소는 F입니다. (보충)
- 금속원소는 전기음성도가 작고, 비금속원소는 큽니다. 원본 메모: *전기음성도가 낮다 = 양성이 강하다 = 금속*.
- 결합 종류는 붙은 원자의 조합으로 판단합니다.

| 조합 | 결합 | 예 |
|---|---|---|
| 금속 + 금속 | 금속결합 | Fe, Cu, Na |
| 비금속 + 비금속 | 공유결합 | H₂O, CO₂, 다이아몬드 |
| 금속 + 비금속 | 이온결합 | NaCl, CaO |

> 함정: NH₄Cl은 비금속 원자만으로 되어 있지만 NH₄⁺와 Cl⁻ 사이는 **이온결합**이고, NH₄⁺ 안에는 **배위결합**이 하나 들어 있습니다. (보충)

## 결정의 특징

아래 표의 예시는 원본에 없고 제가 채운 것입니다. (보충)

| 결정 | 특징 | 예 |
|---|---|---|
| 금속결정 | 금속광택이 있고 전기·열을 잘 전달합니다. 얇게 펴지는 성질(展性, 전성)과 길게 늘어나는 성질(延性, 연성)이 큽니다. | Cu, Al |
| 이온결정 | 단단하고 녹는점이 높습니다. 대신 충격을 받으면 쉽게 깨집니다. 고체는 전기가 통하지 않지만 녹이거나 물에 녹이면 통합니다. | NaCl |
| 분자결정 | 녹는점·끓는점이 낮고 무릅니다. 승화성(昇華性)을 보이는 것이 많습니다. | I₂, 나프탈렌, 드라이아이스 |
| 공유결합결정 | 매우 단단하고 녹는점도 매우 높습니다. | 다이아몬드, Si, SiO₂ |

## 수소결합(水素結合)

F, O, N처럼 전기음성도가 큰 원자 사이에 H 원자가 끼어서 생기는 강한 분자 사이의 인력입니다. 그래서 끓는점 순서가 **H₂O > HF > NH₃**가 됩니다. (보충) 분자량만 보면 예상보다 훨씬 높은 끓는점을 보이는 이유가 이것입니다.

# 2 물질의 분류와 산화물 {#oxide}

원본 2–3쪽입니다.

## 용어 정리

| 일본어 | 한국어 | 뜻 |
|---|---|---|
| 単体 | 홑원소물질 | 한 종류의 원소로만 된 물질입니다. 예: O₂, Fe |
| 化合物 | 화합물 | 두 종류 이상의 원소를 포함한 물질입니다. 예: H₂O |
| 同素体 | 동소체 | 같은 원소로 되어 있지만 성질이 다른 홑원소물질입니다. 예: O₂와 O₃ |
| 酸化物 | 산화물 | 산소와 다른 원소의 화합물입니다. |
| 塩基性酸化物 | 염기성산화물 | **산과** 반응하는 산화물입니다. |
| 酸性酸化物 | 산성산화물 | **염기와** 반응하는 산화물입니다. |
| 両性酸化物 | 양쪽성산화물 | 산과도 염기와도 반응하는 산화물입니다. |
| 水酸化物 | 수산화물 | 수산화물이온 OH⁻를 가진 이온성 물질입니다. |
| オキソ酸 | 옥소산 | 산소원자를 포함한 산입니다. 예: H₂SO₄, HNO₃ |
| 塩 | 염 | 산의 음이온과 염기의 양이온으로 된 화합물입니다. |

> 원본의 「同素体: 성질이 다른 홑원소물질이 두 종류 이상 존재하는 원소」는 **동소체가 있는 원소**를 설명한 문장입니다. 동소체 자체는 그 홑원소물질들(O₂와 O₃ 등)을 가리킵니다.

## 꼭 외울 것

- 동소체가 있는 원소는 **S, C, O, P**가 유명합니다. 암기법: 「SCOP(스콥)」. (보충: 아래 예시)
  - S: 사방황, 단사황, 고무상황
  - C: 다이아몬드, 흑연, 풀러렌
  - O: 산소 O₂, 오존 O₃
  - P: 황린(黄リン), 적린(赤リン)
- 금속원소의 산화물 → 염기성산화물 (예: Na₂O, CaO)
- 비금속원소의 산화물 → 산성산화물 (예: CO₂, SO₂)
- **Al, Zn, Sn, Pb**의 산화물 → 양쪽성산화물. 암기법: 「아(Al) 아(Zn) 스(Sn) 납(Pb)」.

# 3 산·염기와 산화환원 {#redox}

원본 4–6쪽입니다.

## 용어 정리

| 일본어 | 한국어 | 뜻 |
|---|---|---|
| 中和反応 | 중화반응 | 산의 H⁺와 염기의 OH⁻가 만나 물이 생기는 반응입니다. |
| 酸化還元反応 | 산화환원반응 | 전자가 이동하는 반응입니다. |
| 還元剤 | 환원제 | 전자를 내놓아 상대를 환원시키는 물질입니다. **자신은 산화되고, 산화수가 증가합니다.** |
| 酸化剤 | 산화제 | 전자를 받아 상대를 산화시키는 물질입니다. **자신은 환원되고, 산화수가 감소합니다.** |
| 半反応式 | 반쪽반응식 | 산화제와 환원제의 전자 주고받기를 따로따로 나타낸 식입니다. |

> 원본 오타: 酸化剤 설명의 「相手を**参加**する」는 「相手を**酸化**する」입니다.

## 산과 염기의 세기

| 산 | 화학식 | 세기 |
|---|---|---|
| 염화수소(塩化水素) | HCl | 강 |
| 황산(硫酸) | H₂SO₄ | 강 |
| 질산(硝酸) | HNO₃ | 강 |
| 삭산(酢酸) | CH₃COOH | 약 |
| 황화수소(硫化水素) | H₂S | 약 |
| 인산(リン酸) | H₃PO₄ | 약 |
| 슈산(シュウ酸, 옥살산) | (COOH)₂ | 약 |
| 아황산(亜硫酸) | H₂SO₃ | 약 |

| 염기 | 화학식 | 세기 |
|---|---|---|
| 수산화나트륨(水酸化ナトリウム) | NaOH | 강 |
| 수산화바륨(水酸化バリウム) | Ba(OH)₂ | 강 |
| 수산화칼슘(水酸化カルシウム) | Ca(OH)₂ | 강 |
| 수산화구리(II)(水酸化銅(II)) | Cu(OH)₂ | 약 |
| 암모니아(アンモニア) | NH₃ | 약 |

- 강산은 **HCl, H₂SO₄, HNO₃** 세 개만 외우면 됩니다. 원본 표의 「강/약」 표기를 그대로 따랐습니다.
- 강염기는 **알칼리금속**과 **Be, Mg를 뺀 2족 원소**(Ca, Sr, Ba)의 수산화물뿐입니다.

## 대표적인 산화제

| 이름 | 반응 전 | 반응 후 |
|---|---|---|
| 과망간산이온(過マンガン酸イオン) | MnO₄⁻ (적자색) | Mn²⁺ (거의 무색) |
| 이크로뮴산이온(二クロム酸イオン) | Cr₂O₇²⁻ (등적색) | 2Cr³⁺ (녹색) |
| 과산화수소(過酸化水素) | H₂O₂ | 2H₂O |
| 이산화황(二酸化硫黄) | SO₂ | S |
| 진한 질산(濃硝酸) | HNO₃ | NO₂ |
| 묽은 질산(希硝酸) | HNO₃ | NO |
| 뜨거운 진한 황산(熱濃硫酸) | H₂SO₄ | SO₂ |
| 염소(塩素) | Cl₂ | 2Cl⁻ |
| 산소(酸素) | O₂ | 2H₂O |
| 오존(オゾン) | O₃ | O₂ + H₂O |

## 대표적인 환원제

| 이름 | 반응 전 | 반응 후 |
|---|---|---|
| 나트륨(ナトリウム) | Na | Na⁺ |
| 황화수소(硫化水素) | H₂S | S |
| 이산화황(二酸化硫黄) | SO₂ | SO₄²⁻ |
| 과산화수소(過酸化水素) | H₂O₂ | O₂ |
| 슈산(シュウ酸) | (COOH)₂ | 2CO₂ |
| 철(II)이온(鉄(II)イオン) | Fe²⁺ | Fe³⁺ |
| 주석(II)이온(スズ(II)イオン) | Sn²⁺ | Sn⁴⁺ |
| 아이오딘화이온(ヨウ化物イオン) | 2I⁻ | I₂ |
| 싸이오황산이온(チオ硫酸イオン) | 2S₂O₃²⁻ | S₄O₆²⁻ |

## 양쪽으로 쓰이는 물질

- **H₂O₂**는 원칙적으로 산화제입니다. **MnO₄⁻나 Cr₂O₇²⁻처럼 더 강한 산화제**를 만날 때만 예외적으로 환원제로 작용합니다(O₂ 발생).
- **SO₂**는 원칙적으로 환원제입니다. **H₂S**를 만날 때만 예외적으로 산화제로 작용합니다(S 석출).
- MnO₄⁻는 **산성** 용액에서는 Mn²⁺가 되지만, **중성·염기성** 용액에서는 MnO₂(흑색 침전)가 됩니다.

# 4 금속의 반응성 {#metal}

원본 7쪽입니다.

## 용어 정리

| 일본어 | 한국어 | 뜻 |
|---|---|---|
| イオン化傾向 | 이온화경향 | 금속 홑원소물질이 수용액 속에서 양이온이 되려는 성질입니다. |
| 金属のイオン化列 | 금속의 이온화서열 | 이온화경향이 큰 금속부터 차례로 늘어놓은 것입니다. **금속 홑원소물질의 환원력 순서**이기도 합니다. |
| 不動態 | 부동태 | 표면에 치밀한 산화피막이 생겨 금속 내부를 보호하는 상태입니다. |
| 燃焼反応 | 연소반응 | 물질이 산소와 반응해 열과 빛을 내는 반응입니다. |
| 自己酸化還元反応 | 자기산화환원반응 | 같은 물질이 산화제와 환원제 역할을 동시에 하는 반응입니다. 예: 2H₂O₂ → 2H₂O + O₂ |

이온화서열 암기법(일본식): **Li K Ca Na Mg Al Zn Fe Ni Sn Pb (H₂) Cu Hg Ag Pt Au** = 「リッチに貸そうかな、まああてにすんな、ひどすぎる借金」.

## 이온화서열과 반응 (원본 7쪽)

원본 표는 이온화서열 위에 색 띠로 범위를 표시했습니다. 경계가 흐린 부분은 화학적으로 확실한 범위로 적었습니다.

| 반응 | 반응하는 금속 | 반응하지 않는 금속 |
|---|---|---|
| 공기 중 | K, Ca, Na는 즉시 산화, Mg~Fe는 서서히 산화 | Ni 이후는 산화되기 어렵습니다 |
| 물 | Li, K, Ca, Na는 실온에서, Mg는 뜨거운 물과, Al·Zn·Fe는 수증기와 반응 | Ni 이후는 반응하지 않습니다 |
| 염산·묽은 황산 | 수소보다 이온화경향이 큰 Li~Pb | Cu 이후 |
| 질산·뜨거운 진한 황산 | Cu까지 (Al, Fe, Ni은 부동태) | Hg, Ag, Pt, Au |
| 왕수 | Au를 포함한 모든 금속 | |

> 원본 표는 질산·열농황산에 녹지 않는 금속으로 Hg, Ag, Pt, Au를 적었습니다. 다만 **Ag와 Hg도 질산에는 실제로 녹습니다**(Ag + 2HNO₃ → AgNO₃ + NO₂ + H₂O). 원본 표는 「왕수나 질산으로도 안 되는 금속」을 한 칸에 묶은 것이므로, 시험에서는 원본 표기를 따르되 이 예외는 알고 있는 편이 안전합니다. (보충)

## 꼭 외울 것

- 홑원소물질이 관여하는 반응은 일반적으로 산화환원반응입니다.
- 금속 홑원소물질은 일반적으로 **환원제**로 작용합니다.
- 할로젠(ハロゲン)과 산소는 일반적으로 **산화제**로 작용합니다.
- **Al, Fe, Ni**는 진한 질산이나 뜨거운 진한 황산에서 **부동태**가 되어 녹지 않습니다. 암기법: 「あ(Al)て(Fe)に(Ni)すんな」.
- **왕수(王水)**는 진한 질산 : 진한 염산 = **1 : 3** (부피비)으로 섞은 것입니다. Pt, Au도 녹입니다.

## 할로젠 (원본 7쪽)

- 산화력: **F₂ > Cl₂ > Br₂ > I₂**. 원본 메모: *산화력이 크다 = 반응성이 크다*.
- 아이오딘(ヨウ素) 이외의 할로젠 홑원소물질은 물과 반응합니다.
- 아이오딘은 물과는 잘 반응하지 않지만, 아이오딘화칼륨(KI) 수용액에는 녹습니다. (보충: I₃⁻ 생성)

# 5 침전 생성 {#precipitate}

원본 8쪽입니다. 원본 표가 깨져 있어 정리해서 다시 그렸습니다.

- H₂SO₄는 **비휘발성(不揮発性)** 산입니다.

## OH⁻와의 침전

| 양이온 | 결과 |
|---|---|
| Li⁺, K⁺, Ca²⁺, Na⁺ (알칼리금속, Be·Mg를 뺀 2족) | 수산화물이 잘 녹아 **침전하지 않습니다**. |
| Mg²⁺, Al³⁺, Zn²⁺, Fe²⁺, Fe³⁺, Ni²⁺, Sn²⁺, Pb²⁺, Cu²⁺ | **수산화물 침전**이 생깁니다. |
| Hg²⁺, Ag⁺ | 실온에서 수산화물이 바로 분해되어 **산화물 침전**(HgO, Ag₂O)이 생깁니다. |

> 원본 오타: 「水酸化物が**分化**し」는 「水酸化物が**分解**し」입니다.

## S²⁻와의 침전

| 양이온 | 결과 |
|---|---|
| Li⁺, K⁺, Ca²⁺, Na⁺, Mg²⁺, Al³⁺ (이온화서열 위쪽 Li~Al) | 황화물이 **침전하지 않습니다**. |
| (Mn²⁺), Zn²⁺, Fe²⁺, (Co²⁺), Ni²⁺ | **중성·염기성**일 때만 황화물이 침전합니다. |

# 8 기체의 제법과 성질 {#gas}

원본 12–14쪽과 함께 보내 준 「気体の実験的製法」 표를 합쳤습니다. **무기화학에서 가장 많이 나오는 단원입니다.** 최소한 「무엇과 무엇에서 어떤 기체가 나오는가」를 외우고, 반응원리를 같이 알아 두면 처음 보는 반응도 풀 수 있습니다.

## 실험실 제법

| 기체 | 만드는 법 | 반응식 | 반응원리 |
|---|---|---|---|
| H₂ | 아연 + 묽은 황산 | Zn + H₂SO₄ → ZnSO₄ + H₂↑ | 금속 홑원소물질 + 산 |
| O₂ | 과산화수소 + MnO₂(촉매) | 2H₂O₂ → 2H₂O + O₂↑ | 분해반응 |
| O₂ | 염소산칼륨 + MnO₂(촉매), **가열** | 2KClO₃ → 2KCl + 3O₂↑ | 분해반응 |
| O₃ | 산소 속 무성방전, 또는 공기에 자외선 | 3O₂ → 2O₃ | |
| N₂ | 아질산암모늄 **가열** | NH₄NO₂ → N₂↑ + 2H₂O | 분해반응 |
| Cl₂ | 산화망간(IV) + **진한 염산**, **가열** | MnO₂ + 4HCl → MnCl₂ + 2H₂O + Cl₂↑ | 산화환원 |
| Cl₂ | 표백분(さらし粉) + 묽은 염산 | CaCl(ClO)·H₂O + 2HCl → CaCl₂ + 2H₂O + Cl₂↑ | 산화환원 |
| HF | 형석(蛍石) CaF₂ + **진한 황산**, **가열** | CaF₂ + H₂SO₄ → CaSO₄ + 2HF↑ | 휘발성 산의 유리 |
| HCl | 염화나트륨 + **진한 황산**, **가열** | NaCl + H₂SO₄ → NaHSO₄ + HCl↑ | 휘발성 산의 유리 |
| CO | 폼산(ギ酸) + **진한 황산**, **가열** | HCOOH → H₂O + CO↑ | 탈수작용 |
| CO | 슈산 + **진한 황산**, **가열** | (COOH)₂ → H₂O + CO₂↑ + CO↑ | 탈수작용 |
| CO₂ | 석회석 CaCO₃ + 묽은 염산 | CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑ | 약산의 유리 |
| CO₂ | 석회석 **가열** | CaCO₃ → CaO + CO₂↑ | 분해반응 |
| NH₃ | 염화암모늄 + 수산화칼슘, **가열** | 2NH₄Cl + Ca(OH)₂ → CaCl₂ + 2H₂O + 2NH₃↑ | 약염기의 유리 |
| NO | 구리 + **묽은 질산** | 3Cu + 8HNO₃ → 3Cu(NO₃)₂ + 4H₂O + 2NO↑ | 산화환원 |
| NO₂ | 구리 + **진한 질산** | Cu + 4HNO₃ → Cu(NO₃)₂ + 2H₂O + 2NO₂↑ | 산화환원 |
| H₂S | 황화철(II) + 묽은 황산 (또는 묽은 염산) | FeS + H₂SO₄ → FeSO₄ + H₂S↑ | 약산의 유리 |
| SO₂ | 구리 + **진한 황산**, **가열** | Cu + 2H₂SO₄ → CuSO₄ + 2H₂O + SO₂↑ | 산화작용 |
| SO₂ | 아황산수소나트륨 + 묽은 황산 | 2NaHSO₃ + H₂SO₄ → Na₂SO₄ + 2H₂O + 2SO₂↑ | 약산의 유리 |

> 원본 PDF에는 SO₂를 Na₂SO₃ + H₂SO₄ → Na₂SO₄ + H₂O + SO₂↑로, H₂S를 FeS + 2HCl → FeCl₂ + H₂S↑로도 적어 두었습니다. 둘 다 같은 원리(약산의 유리)이므로 어느 쪽으로 나와도 맞습니다.

## 가열이 필요한 반응 3가지

1. **진한 황산을 쓰는 반응.** 가열이 필요한 반응 대부분이 여기에 해당합니다. 비휘발성 성질이나 산화작용은 뜨거운 진한 황산이 되어야 나타나고, 유기물의 탈수도 고온일수록 잘 일어납니다.
2. **고체끼리 반응시키는 경우.** 녹여서 반응하기 쉽게 만듭니다. 예: KClO₃, CaCO₃, NH₄Cl + Ca(OH)₂
3. **Cl₂ 발생(MnO₂ + 진한 염산).** MnO₂에 HCl을 넣기만 해서는 반응이 진행되지 않습니다. 가열해 Cl₂를 계 밖으로 내보내 평형을 오른쪽으로 옮깁니다(르샤틀리에 원리).

## 왜 이런 반응이 일어나는가

- **약산·약염기의 유리**: 탄산 H₂CO₃, 아황산 H₂SO₃, NH₄OH는 불안정해서 바로 분해됩니다.
  - H₂CO₃ → CO₂ + H₂O
  - H₂SO₃ → SO₂ + H₂O
  - NH₄OH → NH₃ + H₂O
- 「아(亜)」는 표준보다 O가 하나 적다는 뜻입니다. 예: H₂SO₃(아황산), HNO₂(아질산).
- **HF는 CaSO₄까지, HCl은 NaHSO₄까지만** 진행합니다. 산의 세기가 H₂SO₄(1단계 전리) > HCl > HSO₄⁻(2단계 전리) > HF 순이기 때문입니다. 더 잘 전리하는 HCl이 남아 있는 동안에는 HSO₄⁻가 전리하지 않습니다.

## 건조제(乾燥剤)

원리는 **서로 반응해 버리는 조합을 피하는 것**입니다. 산성 건조제로 염기성 기체를 말리면 중화되고, H₂S는 진한 황산에 산화되며, CaCl₂는 NH₃와 결합해 버립니다.

| 건조제 | 성질 | 쓰면 안 되는 기체 |
|---|---|---|
| 진한 H₂SO₄ (액체) | 산성 | 염기성(NH₃), 그리고 **H₂S**(산화되어 버림) |
| P₄O₁₀ (고체) | 산성 | 염기성(NH₃) |
| 소다석회 CaO + NaOH (고체) | 염기성 | 산성 기체 전부 |
| CaCl₂ (고체) | 중성 | **NH₃** (CaCl₂·8NH₃를 만듦) |

> CaCl₂는 중성인데도 NH₃에 쓸 수 없다는 점이 단골 함정입니다. (보충)

|---|---|---|
| 상방치환 (上方置換) | NH₃ | 물에 잘 녹고 공기보다 가볍습니다. |
| 하방치환 (下方置換) | H₂S, HCl, NO₂, SO₂, Cl₂, CO₂ | 물에 잘 녹고 공기보다 무겁습니다. |
| 수상치환 (水上置換) | H₂, O₂, N₂, NO, CO | 물에 잘 녹지 않습니다. |

# 9 공업적 제법 {#industry}

원본 13–18쪽의 공업 제법을 모았습니다.

## NaOH — 이온교환막법(イオン交換膜法)

진한 NaCl 수용액을 전기분해해 NaOH를 만듭니다.

| 전극 | 반응 |
|---|---|
| 양극(+) | 2Cl⁻ → Cl₂ + 2e⁻ |
| 음극(−) | 2H₂O + 2e⁻ → H₂ + 2OH⁻ |

Na⁺가 이온교환막을 지나 양극실 → 음극실로 이동하고, 음극 쪽에서 Na⁺ + OH⁻ → NaOH 수용액이 됩니다.

전체 반응: **2NaCl + 2H₂O → 2NaOH + H₂ + Cl₂**

## Na₂CO₃ — 암모니아소다법(ソルベー法, 솔베이법)

전체 반응: **2NaCl + CaCO₃ → Na₂CO₃ + CaCl₂**

## Al — 용융염전해(溶融塩電解)

Al₂O₃·nH₂O(보크사이트) → [Al(OH)₄]⁻ → Al(OH)₃ → Al₂O₃(알루미나) → **용융염전해** → Al

Al은 이온화경향이 커서 수용액을 전기분해하면 H₂만 나옵니다. 그래서 녹은 Al₂O₃를 전기분해합니다(빙정석을 넣어 녹는점을 낮춤).

## Fe

Fe₂O₃(적철석) → Fe₃O₄(자철석) → FeO → Fe(**선철**, 탄소 약 4%) → Fe(**강**, 탄소 약 0.02~2%)

용광로에서 코크스가 만든 CO가 환원제입니다. (보충)

## Cu — 전해정련(電解精錬)

CuFeS₂(황동석) → Cu₂S → Cu(조동, 粗銅) → Cu(순동, 純銅)

| 전극 | 재료 | 반응 |
|---|---|---|
| 양극(+) | 조동 | Cu → Cu²⁺ + 2e⁻ |
| 음극(−) | 순동 | Cu²⁺ + 2e⁻ → Cu |

- 순동은 **음극**에서 얻습니다.
- 양극 아래에는 Cu보다 이온화경향이 작은 Ag, Au가 **양극니(陽極泥)**로 쌓입니다. (보충)

## H₂SO₄ — 접촉법(接触法)

S·FeS₂ → SO₂ → SO₃ → H₂SO₄

SO₂ → SO₃ 촉매: **산화바나듐(V) V₂O₅**

## NH₃ — 하버·보슈법(ハーバー・ボッシュ法)

N₂ + 3H₂ ⇄ 2NH₃ (촉매: Fe₃O₄ 주성분 — 보충)

## HNO₃ — 오스트발트법(オストワルト法)

NH₃ → NO → NO₂ → HNO₃

NH₃ → NO 촉매: **백금 Pt**

## 할로젠 (원본 18쪽)

- **플루오린화수소산(フッ化水素酸)**은 SiO₂와 반응해 유리를 부식시킵니다.
  - SiO₂ + 6HF → H₂SiF₆ + 2H₂O
  - 그래서 유리병이 아니라 **폴리에틸렌 용기**에 보관합니다.

> 원본 오타: 「SiO2+6H2O→H2SiF6+2H2O」의 왼쪽 6H₂O는 **6HF**입니다.
